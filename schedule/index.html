The GAO's ten best practices for a reliable schedule, rated from the checks in this desk. Rating: no failed checks = Fully met, 1 = Substantially, 2 = Partially, 3 = Minimally, 4 or more = Not met. Practices that need a person's review or data the XER doesn't hold are marked.

About BH scores

The Schedule Desk scores every P6 update with two Bailey-Harris scores: the BH Quality Score and the BH Performance Score. They are our scores, not Schedule Validator's. They are built from public standards, the DCMA 14-point assessment and the GAO Schedule Assessment Guide, and every weight is published below so anyone can check a number by hand.

BH Quality Score: is the schedule well built?

Each DCMA check earns 0 to 100 points: 100 when it meets the target, falling in a straight line to 0 at the "zero at" value. The score is the weighted average. Checks that can't be run for an update (no baseline loaded, or this is the baseline) drop out and the other weights are scaled up to 100.

BH Performance Score: is the job doing what the schedule said?

Compares each update with the previous one and with the baseline. Same 0 to 100 points per measure and weighted average. The first update loaded has no previous update, so it has no Performance Score.

Definitions

  • Execution index: tasks the previous update scheduled to start or finish before this data date that did, as a share of all it scheduled.
  • BEI: tasks finished ÷ tasks the baseline planned to finish by this data date.
  • Initial schedule and baselines: tag them in the Schedules table. A job has one initial schedule (it always stays the first reference) and any number of baselines (re-baselines). BEI and missed tasks use the latest tagged schedule before each update's data date. "Vs initial" always compares with the initial schedule. Schedule Validator's flags aren't in the XER file, so they're tagged here. Files with BASE in the name are tagged Baseline automatically.
  • CPLI: (workdays to the forecast finish + float on the finish milestone) ÷ workdays to the forecast finish. Below 1 means the finish can't be met without recovery.
  • Float erosion: average change in total float, in workdays, for open work that had 20 workdays of float or less in the previous update. Negative = float lost.
  • GAO rating: from the checks mapped to each practice. See the GAO best practices view.

What's not in the scores yet

  • DCMA 10 Resources: BH schedules aren't resource-loaded. Shown for information.
  • DCMA 12 Critical path test: needs P6 to recalculate the schedule. A critical path continuity check is shown instead, outside the score.
  • Risk analysis (GAO 8): no risk data in the XER.

Weights version 1, November 2026. A change to the weights gets a new version number here, so old and new scores aren't mixed without notice.
